# ⚡ Muthu Priyarajan M — Pure HTML, CSS & JavaScript Portfolio

A modern, highly animated, futuristic developer portfolio built purely with **HTML5**, **CSS3**, and **Vanilla JavaScript** (Zero Node.js, Zero build step, No npm required).

---

## 🚀 How to Run in VS Code

1. **Option A (Instant)**:
   - Double-click `index.html` in your file explorer to open it in any browser (Chrome, Edge, Firefox).

2. **Option B (VS Code Live Server)**:
   - Open this folder in VS Code (`File > Open Folder...`).
   - Right-click `index.html` and click **"Open with Live Server"**.

---

## 🌐 How to Deploy (Zero Errors)

Because this is a pure static website:
- **Vercel**: Push to GitHub or drag the folder to Vercel dashboard. It deploys in 2 seconds with **no build command needed**!
- **Netlify**: Drag and drop this folder directly into the Netlify Drop box.
- **GitHub Pages**: Push to a GitHub repository, go to **Settings > Pages > Source: main branch > Save**.
